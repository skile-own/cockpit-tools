# polls

Минималистичная настольная панель аккаунтов ChatGPT/Codex, Antigravity и ZCode. Форк [Cockpit Tools](https://github.com/jlcodes99/cockpit-tools); автор исходного проекта — jlcodes99.

Поддерживаемые разделы: Codex и его API-сервис, Antigravity и Antigravity IDE, ZCode. Доступны существующие инструменты импорта, переключения аккаунтов, просмотра квот и управления экземплярами в зависимости от платформы. Аккаунты ChatGPT используются через интеграцию Codex.

Название и иконки заменены на polls. Общий редизайн интерфейса отложен. Старые платформы исключены из навигации, настроек и автоматического обновления; их внутренние форматы сохранены для совместимости.

## Разработка

Требуются Node.js, Rust и Go для прокси-движка.

```sh
npm ci
npm run tauri:dev
```

Проверки: `npm test`, `npm run test:release`, `npm run build`.
